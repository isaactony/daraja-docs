To call the Daraja sandbox, you need a free Daraja account and a sandbox app. The app gives you the keys every request uses.

## Create an account and an app

1. Sign up at [developer.safaricom.co.ke](https://developer.safaricom.co.ke). You need an email address you can verify.
2. Go to **My Apps** and create a sandbox app.
3. Select the API products the app needs, such as **M-Pesa Express** for STK Push.

<Note>
  One app can have **either** C2B **or** B2C, not both. If you need both, create two apps. This comes from the official FAQ.
</Note>

## Find each value

| Value | Where to find it | Used for |
| :-- | :-- | :-- |
| Consumer key and consumer secret | **My Apps** → your app → **Keys** | Getting an access token, for every API |
| STK Push shortcode | `174379`, the sandbox's Lipa na M-Pesa Online test shortcode | `BusinessShortCode` and `PartyB` in STK Push |
| Passkey | Dashboard → **Test Credentials**, as `Passkey` | Building the STK Push `Password` |
| C2B and B2C test shortcode | Dashboard → **Test Credentials**, as **Party A** (`600995`) | `ShortCode` (C2B) and `PartyA` (B2C) |
| Initiator name and password | Dashboard → **Test Credentials** (the name is `testapi`) | B2C, Transaction Status, Reversal, and Account Balance |
| Public key certificate (sandbox) | The official [Getting Started](https://developer.safaricom.co.ke/apis/GettingStarted) page | Encrypting the initiator password into a `SecurityCredential` |

The test credentials, the simulator, and the Postman collection appear only when you're logged in. All test credentials are shared by every developer; only your consumer key and secret are yours. See [Sandbox test values](/reference/sandbox-test-values).

## Store them as environment variables

Never put keys in your code or commit them. The examples in these docs read these variables:

```bash .env
DARAJA_ENV=sandbox
DARAJA_CONSUMER_KEY=your-consumer-key
DARAJA_CONSUMER_SECRET=your-consumer-secret
DARAJA_SHORTCODE=174379
DARAJA_PASSKEY=your-sandbox-passkey
DARAJA_CALLBACK_URL=https://your-domain.example/payments/stk-callback
```

Add `.env` to your `.gitignore`. In production, use your hosting platform's secret settings.

<Warning>
  Don't paste your consumer secret, passkey, or initiator password into an AI chat. Give the AI tool the variable names instead.
</Warning>

## Test with real money, carefully

In the sandbox, an STK Push sends a **real prompt to a real Safaricom phone**, and entering your PIN moves real money. According to the official FAQ, Safaricom reverses sandbox test payments automatically at 6 AM the next day. Use your own number and an amount of **Ksh 1**.
