AI coding assistants often get Daraja details wrong from memory: the password format, the timestamp, paybill versus till fields, or old endpoint versions. These docs are built so an AI tool can read them directly and answer from them.

The official Daraja portal builds its pages with JavaScript and doesn't publish an `llms.txt` file, so tools that fetch pages without running JavaScript get an empty page. Every page here is also available as plain Markdown.

## Choose a connection method

| Method | Best for | What the AI gets |
| :-- | :-- | :-- |
| [MCP server](#connect-the-docs-mcp-server) | Claude, Cursor, VS Code, and other MCP clients | Search over every page, on demand |
| [Agent skill](#install-the-daraja-skill) | Coding agents such as Claude Code | Daraja's rules, formats, and common mistakes |
| [Page as Markdown](#give-an-ai-a-single-page) | Any chat assistant | One page, pasted or linked |
| [llms.txt](#point-an-ai-at-llms-txt) | Tools that crawl a site | A list of every page with a one-line description |

The server only searches these public docs. It can't reach your Daraja account, your keys, or your transactions.

## Install the Daraja skill

The skill gives a coding agent Daraja's request formats, the rules that cause most errors, and what to check before it writes payment code.

<Visibility for="humans">
Paste this prompt into your coding agent:

<Prompt description="Install the Daraja skill in your coding agent." icon="sparkles" actions={["copy", "cursor"]}>
Install the Daraja docs skill so you can help me integrate M-Pesa.

1. Run `npx skills add https://safaricom-safaricom-daraja-docs.mintlify.site`.
2. Print the name and description of each skill that was installed.
3. Summarize in one paragraph what you can now help me do with Daraja.
4. Before writing payment code, ask whether I use a paybill or a till, and read keys only from environment variables.
</Prompt>
</Visibility>

## Give an AI a single page

- Open the menu at the top of any page and select **Copy page**, **Open in ChatGPT**, or **Open in Claude**.
- Or add `.md` to the page URL, for example `https://safaricom-safaricom-daraja-docs.mintlify.site/quickstart.md`.

## Point an AI at llms.txt

`/llms.txt` lists every page with its description, and `/llms-full.txt` contains the full text of every page in one file.

## Get better answers from AI tools

- Say whether you're collecting payments into a **paybill** or a **till**. Several fields depend on it.
- Paste the exact `errorCode` and `errorMessage`, such as `500.001.1001` and `Wrong credentials`.
- Say whether you're in the sandbox or production.
- Never paste your consumer secret, passkey, or initiator password. Describe them by name.
- Ask the AI to link the page it used, so you can check the answer.
